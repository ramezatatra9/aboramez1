📖 دليل سريع: كيف تجهز بوت تيليجرام في دقيقتين؟

  1. افتح تطبيق تيليجرام وابحث عن المستخدم الرسمي: @BotFather
  2. أرسل له الأمر /newbot ثم اكتب اسماً للبوت، ثم معرف للبوت ينتهي بكلمة bot.
  3. سيمنحك BotFather رمز الـ HTTP API Token (انسخه وضعه في خانة Bot Token أعلاه).
  4. لمعرفة الـ Chat ID الخاص بك: ابحث في تيليجرام عن بوت @userinfobot واضغط Start، وسيعطيك رقم الـ Id الخاص بحسابك فوراً.
  5. ملاحظة هامة: افتح البوت الذي أنشأته واضغط على زر Start لمرة واحدة حتى يسمح له تيليجرام بإرسال الرسائل إليك.
  6. الصق الـ Token والـ Chat ID هنا واضغط زر فحص الاتصال وإرسال رسالة تجريبية!
